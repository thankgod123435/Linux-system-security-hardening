# Linux System Security and Hardening

## Project Overview
This project demonstrates practical Linux system security and hardening concepts using Kali Linux.

## Objectives
- Understand Linux system security.
- Review user accounts and permissions.
- Examine firewall configuration.
- Understand SSH security.
- Review system updates and maintenance.

## Tools Used
- Kali Linux
- Linux Terminal
- Linux system administration commands

## Practical Exercises
1. System information and security checks.
2. User and permission management.
3. Firewall status review.
4. SSH security review.
5. System update and maintenance checks.

## Learning Outcomes
- Understanding Linux security fundamentals.
- Learning basic Linux administration.
- Reviewing system security configurations.
- Practising defensive security checks.

## Disclaimer
All exercises are performed on my own virtual machine for educational and defensive cybersecurity purposes.
